# 4. Ejecución y pruebas

## 4.1. Ejecución de la aplicación

Actualmente ejecutamos Pokémon Store en local mediante Spring Boot.

Para iniciar la aplicación utilizamos Maven, que permite compilar el proyecto y ejecutar la aplicación con la configuración definida.

Una vez iniciada, podemos realizar peticiones y comprobar el comportamiento de las funcionalidades implementadas.

## 4.2. Pruebas manuales

Actualmente realizamos las pruebas de forma manual, ejecutando la aplicación con Spring Boot y accediendo a ella desde el navegador mediante `localhost`.

A través del navegador comprobamos las respuestas de la aplicación y verificamos que las funcionalidades implementadas se comportan correctamente.

Entre las operaciones que comprobamos se encuentran:

- Consulta de Pokémon.
- Creación de nuevos Pokémon.
- Modificación de Pokémon existentes.
- Eliminación de Pokémon.

También comprobamos el comportamiento de las validaciones y la respuesta de la aplicación ante situaciones de error.

## 4.3. Evidencias de ejecución

En este apartado incorporaremos capturas de pantalla que permitan mostrar el funcionamiento de las diferentes funcionalidades de Pokémon Store.

Las capturas se añadirán conforme vayamos realizando y documentando las comprobaciones.
