# 5. Herramientas y versiones

En este apartado recogemos las herramientas y tecnologías utilizadas durante el desarrollo de Pokémon Store, junto con sus versiones.

## 5.1. Lenguajes y tecnologías

| Herramienta | Versión |
|---|---|
| Java | 17 |
| Spring Boot | 3.3.0 |
| MapStruct | 1.6.3 |
| Lombok | 1.18.32 |
| Lombok-MapStruct Binding | 0.2.0 |

## 5.2. Herramientas de desarrollo

| Herramienta | Versión |
|---|---|
| Apache Maven | 3.9.9 |
| Git | 2.47.3 |
| Visual Studio Code | 1.138.0 |

## 5.3. Otras herramientas

- **GitHub:** plataforma utilizada para alojar el repositorio del proyecto y colaborar en su desarrollo.
- **Navegador web:** utilizado para acceder a la aplicación durante las pruebas locales.
