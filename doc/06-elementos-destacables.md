# 6. Elementos destacables

Durante el desarrollo de Pokémon Store hemos aplicado diferentes conceptos y herramientas relacionados con la arquitectura y el desarrollo de aplicaciones web. Al tratarse de un proyecto académico de segundo curso de DAW, también nos está sirviendo para aprender y poner en práctica nuevos conceptos.

## 6.1. Arquitectura Clean Architecture

Uno de los aspectos destacables del proyecto es la utilización de **Clean Architecture**. Esta arquitectura permite organizar el código separando las distintas responsabilidades de la aplicación, facilitando su mantenimiento y evolución.

## 6.2. Organización mediante Vertical Slicing

También hemos incorporado el enfoque de **Vertical Slicing**, organizando el proyecto por funcionalidades en lugar de agrupar todo el código únicamente por capas técnicas.

Actualmente contamos con dos slices:

- **pokemon:** contiene los elementos relacionados con la funcionalidad de los Pokémon.
- **common:** contiene elementos compartidos que pueden utilizarse en distintas partes de la aplicación.

Esta organización nos permite mantener agrupado el código relacionado con cada funcionalidad.

## 6.3. Aprendizaje durante el desarrollo

El proyecto nos permite aplicar de forma práctica los contenidos que vamos aprendiendo durante el curso. A medida que desarrollamos nuevas funcionalidades, vamos incorporando conceptos relacionados con Spring Boot, la arquitectura del software y la organización del código.
