## 8.3. Conclusión de Samuel Alonso Álvarez

Con este proyecto estamos aprendiendo de forma práctica a realizar aplicaciones web desde cero, poniendo énfasis en la arquitectura del proyecto y en separar responsabilidades entre capas.

De este modo, nos centramos en proponer una solución que tiene como fin añadir funcionalidades a la aplicación sin tener que modificar el código completo.
